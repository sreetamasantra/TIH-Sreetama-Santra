# Project- Battery State of Charge (SoC) Estimation and Remaining Charging Time Prediction using Machine Learning
Predicting two critical battery parameters from sensor data:
- State of Charge (SoC) — percentage of energy remaining in a lithium-ion battery
- Remaining Charging Time — minutes until the battery reaches full charge
Dataset used: LG HG2 18650 Li-ion Battery Dataset (McMaster University, Dr. Phillip Kollmeyer) — 211 CSV files across 6 temperature conditions (-20°C to 40°C)
